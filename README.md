# 💳 Credit Risk Scoring System

**End-to-End Machine Learning Project | Production-Ready Architecture**

A professional ML engineering project that predicts customer credit risk using a complete pipeline-based architecture with preprocessing, model training, API deployment, and web UI integration.

---

## 🚀 Project Overview

Classifies customers into **High Risk** or **Low Risk** using machine learning on the German Credit Dataset (1000 samples).

**Flow:** `UI → API → src.components.preprocess → ML Pipeline → Prediction → Risk Output`

## 🔄 ML Pipeline — Notebook Steps

| # | Notebook | Description |
|---|----------|-------------|
| 01 | `01_data_preprocessing` | Load raw data, handle missing values, encode target, save cleaned CSV |
| 02 | `02_eda` | Distributions, box plots, default rates by category, pairplot |
| 03 | `03_statistical_analysis` | Correlation heatmap, Chi-Square test, Mann-Whitney U hypothesis test |
| 04 | `04_feature_engineering` | Create `Credit_per_Duration`, `Age_Group`, train-test split (80/20 stratified) |
| 05 | `05_model_training` | Build sklearn pipelines, 5-fold CV, train LR / RF / XGBoost |
| 06 | `06_model_evaluation_deployment` | Confusion matrices, ROC curves, feature importance, save best model |

> Run notebooks **in order** — each step reads outputs saved by the previous step.

## 🔌 API Endpoint

**POST** `/predict`

```json
// Input
{
  "Age": 35, "Job": 2, "Sex": "male", "Housing": "own",
  "Saving accounts": "little", "Checking account": "moderate",
  "Credit amount": 5000, "Duration": 24, "Purpose": "car"
}

// Output
{
  "prediction": 0,
  "risk_probability": 0.23,
  "risk_label": "LOW RISK"
}
```

**risk_probability** is the probability of being HIGH RISK (0.0 = safe, 1.0 = risky).  
Threshold: `>= 0.5` → HIGH RISK, `< 0.5` → LOW RISK.

## ⚙️ How to Run

### Step 1 — Install Python 3.11.3
Download from: https://www.python.org/downloads/release/python-3113/
- Check **Add Python to PATH** during installation
- Install to `C:\Users\<username>\AppData\Local\Programs\Python\Python311`

---

### Step 2 — Clone the repository
```powershell
git clone https://github.com/<your-username>/Credit-Risk-Scoring-System.git
cd Credit-Risk-Scoring-System
```

---

### Step 3 — Create & activate virtual environment
```powershell
& "C:\Users\<username>\AppData\Local\Programs\Python\Python311\python.exe" -m venv ml_env
ml_env\Scripts\activate
```

---

### Step 4 — Install dependencies
```powershell
pip install flask pandas numpy scikit-learn xgboost joblib streamlit matplotlib seaborn scipy requests jupyter
```

---

### Step 5 — Run notebooks in order to train the model
```powershell
jupyter notebook
```
Open and run each notebook **top to bottom** in this order:

| Order | Notebook | What it does |
|-------|----------|--------------|
| 1st | `notebook/01_data_preprocessing/01_data_preprocessing.ipynb` | Cleans data, saves `cleaned_data.csv` |
| 2nd | `notebook/02_eda/02_eda.ipynb` | Visualizes distributions and patterns |
| 3rd | `notebook/03_statistical_analysis/03_statistical_analysis.ipynb` | Chi-Square, correlation, hypothesis tests |
| 4th | `notebook/04_feature_engineering/04_feature_engineering.ipynb` | Creates features, saves train/test splits |
| 5th | `notebook/05_model_training/05_model_training.ipynb` | Trains models with cross-validation |
| 6th | `notebook/06_model_evaluation_deployment/06_model_evaluation_deployment.ipynb` | Evaluates models, saves `credit_risk_model.pkl` |

> ⚠️ Run notebooks in order — each step depends on outputs from the previous step.

---

### Step 6 — Start Flask backend (Terminal 1)
```powershell
ml_env\Scripts\activate
python backend\app.py
```
Flask runs at: `http://127.0.0.1:5000`

---

### Step 7 — Start Streamlit frontend (Terminal 2)
```powershell
ml_env\Scripts\activate
streamlit run frontend\app.py
```
Streamlit opens at: `http://localhost:8501`

---

> 💡 To enable Flask debug mode:
> ```powershell
> $env:FLASK_DEBUG="true"
> python backend\app.py
> ```
